# Scénario silencieux
0–4 s : « Le danger vient de l’espace. » Une défense se rapproche du porteur, à gauche.
4–8 s : « Le ballon change de côté. » La passe latérale atteint le côté libre.
8–12 s : « Le joueur attaque l’espace libre. » Course et passe convergent dans ce couloir.
12–15 s : « Déplacer le ballon. Libérer la course. » Arrêt de synthèse sur la trajectoire utile.

Narration : désactivée. Ces durées sont des choix éditoriaux, pas des timings de voix mesurés.

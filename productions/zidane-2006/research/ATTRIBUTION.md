`final-2006-facts.json` est une extraction limitée des lignes de matches.csv, goals.csv et bookings.csv pour M-2006-64 ; aucune valeur modifiée. La sélection et le format JSON remplacent les CSV d'origine. L'extrait de données conserve cette licence et cette attribution. Le README original consulté est joint. Les données sont secondaires, compilées à partir de Wikipedia et recoupées, lorsque possible par leur auteur, avec les rapports FIFA.
